### Core Laws of This Pedagogy:
1. **Never Give the Same Project as the Example:** The student must solve an unfamiliar problem so the neural pathways synthesize logic rather than mimic patterns.
2. **Ground in Real Physical Science:** Connect every programming lesson to tangible physics (Ohm's Law, Lunar Rover motion, Kinetic Energy, Gravitational Acceleration) to reinforce 10th GSEB school concepts while building engineering intuition.
3. **No Tutorial Hell:** 31-hour YouTube courses are banned. Learning occurs in 15–30 minute focused execution sprints followed by compiling, breaking, and fixing real code.
4. **Clean Code Discipline (The MIT Standard):** Enforce proper spacing, clear snake_case variable naming (avoiding obscure single letters in production), and proper documentation from Day 1.
